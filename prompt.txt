2. TECH-STACK
======================================================================
- React 19 + TypeScript, gebaut mit Vite 7 (vite.config.ts, @vitejs/plugin-react-swc).
- Styling: Tailwind CSS v3 (tailwind.config.js, postcss.config.js) + eigenes CSS in
  src/global.css mit CSS-Variablen für Farb-Themes (HSL-basiert, kompatibel mit shadcn/ui).

  avatar.tsx, badge.tsx, button.tsx, card.tsx, input.tsx, separator.tsx), gebaut mit
  class-variance-authority + tailwind-merge (cn()-Helper in src/lib/utils.ts).

- Routing: react-router-dom nur für die 404-Seite (src/components/error/NotFound.tsx).
- Deployment: Cloudflare Pages (kein eigenes Backend mehr vorhanden — frühere
  Chatbot/Kalender-AI-Funktionen mit Cloudflare Pages Functions + Supabase + Gemini API wurden
  komplett entfernt, inkl. aller Credentials).
- Kein Dark/Light-Mode-Package, sondern eigene Implementierung via `theme-dark` / `theme-light`
  Klassen auf <body>, gesteuert über NavBar (Sonne/Mond-Toggle-Button), Speicherung in
